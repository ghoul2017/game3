# 方块地牢2 游戏设计深度拆解

## 核心玩法循环
**选择 → 探索 → 战斗 → 成长**
- 选择阶段：选职业组合和技能搭配
- 探索阶段：随机地牢中选择路线，遭遇不同事件
- 战斗阶段：文字策略战斗，利用职业优势和技能组合
- 成长阶段：击败敌人获得经验和道具，提升角色

## 职业系统（三层架构）
- 7种基础职业（炼金、法师、刺客、狂战、咒师、防战、信徒）
- 1主2副职业组合系统 → 丰富战术可能性
- 156个技能与职业系统紧密结合
- 每个职业有独特技能树和天赋路径

## 技能系统（多类型分层）
- 主动技能、被动技能、天赋系统、Buff系统、遗物系统
- 技能间存在协同效应和组合技
- 职业加成使特定技能对特定职业更强

## 属性体系
- 基础：力量、敏捷、智力、体力
- 战斗：攻击力、防御力、生命值、法力值
- 特殊：暴击率、闪避率、抗性、穿透

## Roguelike机制
- 随机地牢布局（房间、通道、陷阱、怪物位置）
- 进度保留系统（死亡保留部分进度）
- 随机事件系统

## 关卡设计
- 多层区域，每层不同主题和敌人
- 路径选择提供不同奖励和挑战
- 定期Boss战，特殊事件关卡，隐藏关卡

## 商业模式
- Steam 一次性买断，20元
