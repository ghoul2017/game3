# 方块与地下城 — 游戏设计

**Why:** 这是项目的核心设计文档，所有开发以此为准。
**How to apply:** 开发新功能前先对照此文档确认设计意图。

## 基本信息
- 游戏名：《方块与地下城》
- 参考：《方块地牢2》
- 引擎：Unity 2021.3.26f1c1, URP 2D

## 核心玩法
- 玩家从**城镇**出发，去**地下城**冒险成长，返回补给，继续冒险，直到打通地下城
- 战斗探索参考方块地牢，添加**城镇和返回**概念
- 城镇可恢复、更新装备、学习技能
- 返回后地下城的部分对象恢复（小怪、泉水）

## 职业系统（5职业）
- 战士：近战物理输出，高攻击高生命
- 游侠：远程物理输出，高暴击高闪避
- 骑士：近战坦克，高防御高生命
- 牧师：治疗辅助，高法力高恢复
- 法师：远程魔法输出，高魔法伤害

## 养成系统
- 等级：经验升级，属性成长
- 技能：主动/被动/Buff，按职业分配
- 宝物（遗物）：特殊被动效果
- 装备：武器/防具/饰品三个槽位

## 技术决策
- UI框架：UIManager单例 + UIPanel基类 + 栈式导航
- UI构建：预制体模式（PrefabGenerator生成 + BindReferences绑定）
- 场景管理：单场景 + UI面板切换
- 数据存储：本地JSON存档
- 配置系统：代码内初始化（ConfigManager），后续可迁移到JSON/CSV
