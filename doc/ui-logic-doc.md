# UI功能描述文档

> 本文档描述每个界面能干什么、有哪些交互、预期行为是什么。
> 用于验证UI功能是否正常工作。

---

## 1. MainPanel（主菜单）

### 界面内容
- 游戏标题 "方块与地下城"
- 副标题 "冒险，从城镇开始..."
- 4个按钮 + 底部版本号

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| M-01 | 点击"开始冒险" | 进入创建角色界面（CreateRolePanel） |
| M-02 | 点击"继续冒险"（有存档） | 加载存档，进入城镇（TownPanel） |
| M-03 | 点击"继续冒险"（无存档） | 按钮灰色不可点击 |
| M-04 | 点击"设置" | 弹出设置面板（SettingsPanel） |
| M-05 | 点击"退出游戏" | 关闭游戏（Editor下停止播放） |

### 验证要点
- [ ] 无存档时"继续冒险"按钮是否灰色不可交互
- [ ] 有存档时"继续冒险"按钮是否可点击且正常加载

---

## 2. CreateRolePanel（创建角色）

### 界面内容
- 标题"选择职业"
- 5个职业按钮：战士、游侠、骑士、牧师、法师
- 职业详情面板（名称、描述、基础属性、战斗属性）
- 角色名输入框
- 提示文本（红色错误信息）
- "开始游戏"和"返回"按钮

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| C-01 | 点击不同职业按钮 | 选中该职业，按钮高亮，详情面板更新为该职业信息 |
| C-02 | 查看职业详情 | 显示：职业名、描述、4项基础属性（力量/敏捷/智力/体力+成长率）、6项战斗属性（生命/法力/攻击/防御/暴击/闪避） |
| C-03 | 在输入框输入角色名 | 文本框显示输入内容 |
| C-04 | 输入框为空时点击"开始游戏" | 使用默认名"冒险者"创建角色 |
| C-05 | 点击"开始游戏" | 创建角色，初始化属性，学习默认技能，自动装备技能，进入城镇（TownPanel） |
| C-06 | 点击"返回" | 返回主菜单（MainPanel） |

### 验证要点
- [ ] 首次进入时默认选中战士，详情显示战士信息
- [ ] 切换职业后详情面板是否立即更新
- [ ] 创建角色后角色属性是否与职业配置一致
- [ ] 默认技能是否已学习且已装备

---

## 3. TownPanel（城镇）

### 界面内容
- 标题"城镇"
- 顶部角色信息栏（名称、等级、职业、HP、MP、金币、地牢层数）
- 6个功能按钮

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| T-01 | 查看信息栏 | 显示当前角色的完整信息摘要 |
| T-02 | 点击"进入地牢" | 生成地牢楼层，进入地牢界面（DungeonPanel） |
| T-03 | 点击"休息恢复" | HP/MP恢复到满，自动存档，信息栏更新 |
| T-04 | 点击"商店" | 弹出商店面板（ShopPanel） |
| T-05 | 点击"技能学习" | 弹出技能学习面板（SkillLearnPanel） |
| T-06 | 点击"角色信息" | 弹出角色信息面板（RoleInfoPanel） |
| T-07 | 点击"存档退出" | 保存游戏，返回主菜单（MainPanel） |

### 验证要点
- [ ] 休息恢复后HP/MP是否满值
- [ ] 进入地牢时层数是否正确（首次为1层）
- [ ] 从地牢返回后信息栏是否更新

---

## 4. DungeonPanel（地牢）

### 界面内容
- 标题栏（显示当前层数）
- 顶部状态栏（房间进度，如"房间 3/8"）
- 左侧地图区（房间网格，不同颜色/图标表示类型）
- 右侧状态面板（HP/MP/EXP条、层数、金币、攻防）
- 底部技能快捷栏（4个技能槽）
- 底部3个按钮：返回城镇、背包、角色

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| D-01 | 查看地图 | 显示所有房间，不同类型有不同颜色和图标（怪/精/王/宝/泉/商/梯） |
| D-02 | 查看当前房间 | 当前房间蓝色高亮+金色边框，显示"当前" |
| D-03 | 查看已清房间 | 已清房间灰色，显示"已清" |
| D-04 | 点击当前房间 | 无事发生（已清则刷新） |
| D-05 | 点击下一个房间 | 移动到该房间，触发房间事件 |
| D-06 | 点击非相邻房间 | 无反应（按钮不可交互） |
| D-07 | 进入怪物房间 | 进入战斗（BattlePanel） |
| D-08 | 进入宝箱房间 | 弹出消息：获得金币，可能获得宝物或消耗品，房间标记已清 |
| D-09 | 进入泉水房间 | 弹出消息：恢复1/3 HP和MP，房间标记已清 |
| D-10 | 进入商人房间 | 打开商店面板（ShopPanel） |
| D-11 | 进入出口房间 | 生成下一层地牢，层数+1，刷新界面 |
| D-12 | 点击消息覆盖层"继续" | 关闭消息，继续探索 |
| D-13 | 查看技能快捷栏 | 显示已装备技能名称和MP消耗 |
| D-14 | 点击"返回城镇" | 保存进度，返回城镇（TownPanel） |
| D-15 | 点击"背包" | 弹出背包面板（BagPanel） |
| D-16 | 点击"角色" | 弹出角色信息面板（RoleInfoPanel） |

### 验证要点
- [ ] 地图房间颜色/图标是否与类型匹配
- [ ] 只有当前房间和下一房间可点击
- [ ] 战斗胜利后房间是否标记已清
- [ ] 进入下一层后地图是否重新生成
- [ ] 消息覆盖层是否正确显示和关闭

## 5. BattlePanel（战斗）

### 界面内容
- 标题"战斗"
- 怪物信息区（图标、名称、类型、HP条、攻防）
- 战斗日志区（最近6条战斗记录）
- 玩家信息条（HP/MP/攻击/防御/Buff状态）
- 4个操作按钮：攻击、技能、物品、逃跑
- 技能子面板（8行技能列表，默认隐藏）
- 物品子面板（8行消耗品列表，默认隐藏）
- 战斗结果按钮（默认隐藏）

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| B-01 | 查看怪物信息 | 显示怪物名称、图标（普通"怪"/BOSS"王"）、HP条、攻防数值 |
| B-02 | 点击"攻击" | 玩家普通攻击怪物，然后怪物反击，日志更新，HP条更新 |
| B-03 | 点击"技能" | 显示技能子面板，列出已装备技能及MP消耗 |
| B-04 | 技能面板中点击可用技能 | 释放技能，扣MP，效果生效，怪物反击，关闭技能面板 |
| B-05 | 技能面板中MP不足的技能 | 按钮灰色不可交互，文字显示灰色 |
| B-06 | 点击技能面板"关闭" | 关闭技能面板 |
| B-07 | 点击"物品" | 显示物品子面板，列出消耗品及数量和效果 |
| B-08 | 物品面板中点击物品 | 使用物品，恢复HP/MP，从背包移除，怪物反击，关闭物品面板 |
| B-09 | 物品面板中无消耗品 | 显示"没有可用的消耗品"提示 |
| B-10 | 点击物品面板"关闭" | 关闭物品面板 |
| B-11 | 点击"逃跑" | 50%概率逃跑成功，成功则返回地牢；失败则怪物攻击一次 |
| B-12 | 怪物HP归零（胜利） | 4个操作按钮不可交互，显示"继续探索"按钮 |
| B-13 | 玩家HP归零（失败） | 4个操作按钮不可交互，显示"返回城镇"按钮 |
| B-14 | 点击"继续探索" | 返回地牢面板（UIManager.Back） |
| B-15 | 点击"返回城镇" | 角色满血复活，返回城镇（TownPanel） |
| B-16 | 查看战斗日志 | 最多显示最近6条战斗信息 |
| B-17 | 查看玩家信息条 | 显示HP/MP/攻击/防御，有Buff时显示加成值和剩余回合 |

### 验证要点
- [ ] 攻击伤害是否有浮动（DAMAGE_VARIANCE_RATE=0.1）
- [ ] 怪物是否有概率使用技能（MONSTER_SKILL_CHANCE=0.3）
- [ ] 逃跑成功率是否约50%
- [ ] 战斗失败后角色是否满血复活
- [ ] 使用物品后物品是否从背包移除
- [ ] Buff效果是否正确显示和衰减

## 6. BagPanel（背包）

### 界面内容
- 标题"背包"
- 物品列表（最多20行）
- 空背包提示
- 底部信息栏（容量 X/N + 金币）
- "返回"按钮

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| G-01 | 查看物品列表 | 按物品ID分组显示：[类型] 名称 x数量 属性 |
| G-02 | 背包为空时 | 显示"背包是空的"提示 |
| G-03 | 武器/防具/饰品行 | 显示"装备"按钮（可装备时）或"已装备"（已装备时） |
| G-04 | 点击"装备" | 装备该物品，原装备放回背包，属性重新计算，列表刷新 |
| G-05 | 点击"已装备" | 按钮不可交互，显示绿色"已装备" |
| G-06 | 消耗品行 | 显示"使用"按钮 |
| G-07 | 点击"使用" | 使用消耗品，恢复HP/MP，物品从背包移除，列表刷新 |
| G-08 | 所有物品行 | 显示"卖X金"按钮（售价=原价/2） |
| G-09 | 点击"卖X金" | 出售物品，获得金币，物品从背包移除，列表刷新 |
| G-10 | 点击"返回" | 返回上一界面 |
| G-11 | 查看信息栏 | 显示"容量: 当前数/最大数    金币: X" |

### 验证要点
- [ ] 装备武器后攻击力是否正确增加
- [ ] 装备防具后防御力是否正确增加
- [ ] 更换装备时旧装备是否放回背包
- [ ] 背包满时是否无法购买新物品
- [ ] 出售价格是否为购买价格的一半

---

## 7. ShopPanel（商店）

### 界面内容
- 标题"商店"
- 金币显示栏
- 商品列表（8行一页）
- 翻页按钮（上一页/下一页）
- "返回"按钮

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| S-01 | 查看商品列表 | 显示所有武器/防具/饰品/消耗品，含名称和属性 |
| S-02 | 查看购买按钮 | 显示"X金"价格，金币足够且背包未满时可点击（金色），否则灰色 |
| S-03 | 点击可购买的商品 | 扣除金币，物品加入背包，列表刷新 |
| S-04 | 金币不足时购买 | 按钮灰色不可交互 |
| S-05 | 背包已满时购买 | 按钮灰色不可交互 |
| S-06 | 点击"上一页" | 显示上一页商品，首页时按钮不可交互 |
| S-07 | 点击"下一页" | 显示下一页商品，末页时按钮不可交互 |
| S-08 | 点击"返回" | 返回上一界面 |

### 验证要点
- [ ] 商品列表是否包含所有类型的物品
- [ ] 购买后金币是否正确扣除
- [ ] 购买后背包是否增加对应物品
- [ ] 翻页逻辑是否正确

## 8. SkillLearnPanel（技能学习）

### 界面内容
- 标题"技能学习"
- 金币和装备数信息栏
- 技能列表（8行，当前职业可学技能）
- 已装备技能区（装备/卸下按钮）
- "返回"按钮

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| K-01 | 查看技能列表 | 显示当前职业所有技能：名称 [类型] 威力 MP消耗 描述 前置技能 |
| K-02 | 已学技能行 | 显示绿色背景+绿色"已学"按钮（不可交互） |
| K-03 | 可学技能行 | 显示"X金"按钮（满足条件时金色可点击，不满足时灰色） |
| K-04 | 点击"X金"学习技能 | 扣除金币，学会技能，自动装备（有空位时），列表刷新 |
| K-05 | 不满足前置技能时 | 按钮灰色不可交互 |
| K-06 | 等级不足时 | 按钮灰色不可交互 |
| K-107 | 金币不足时 | 按钮灰色不可交互 |
| K-08 | 查看已装备技能区 | 已装备技能显示"名称 ×"（红色，点击卸下） |
| K-09 | 点击"×"卸下技能 | 从装备栏移除该技能，区域刷新 |
| K-10 | 未装备的已学技能 | 显示"名称 +"（绿色，点击装备） |
| K-11 | 点击"+"装备技能 | 将技能加入装备栏，区域刷新 |
| K-12 | 装备栏已满时 | 不再显示"+"按钮 |
| K-13 | 点击"返回" | 返回上一界面 |

### 验证要点
- [ ] 学习技能后金币是否正确扣除
- [ ] 有前置技能要求的技能是否正确限制
- [ ] 学习后是否自动装备（有空位时）
- [ ] 卸下技能后是否可重新装备
- [ ] 装备栏满后是否无法继续装备

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| R-01 | 查看属性面板 | 显示：力量、敏捷、智力、体力、生命、法力、攻击、防御、暴击率、闪避率 |

| R-06 | 点击"返回" | 返回上一界面 |

### 验证要点
- [ ] 属性值是否与实际数据一致
- [ ] 装备名称是否与背包中的装备一致
- [ ] 经验条进度是否正确

## 10. SettingsPanel（设置）

### 界面内容
- 标题"设置"
- 5行设置项：音乐音量、音效音量、全屏模式、分辨率、语言
- "返回"按钮

### 功能清单

| 编号 | 操作 | 预期行为 |
|------|------|----------|
| SET-01 | 拖动音乐音量滑块 | 实时更新音量值(0-100)显示 |
| SET-02 | 拖动音效音量滑块 | 实时更新音量值(0-100)显示 |
| SET-03 | 点击全屏模式按钮 | 切换全屏/窗口模式，按钮文字切换 |
| SET-04 | 点击分辨率"<" | 切换到上一个分辨率选项 |
| SET-05 | 点击分辨率">" | 切换到下一个分辨率选项 |
| SET-06 | 点击语言"<" | 切换到上一个语言选项 |
| SET-07 | 点击语言">" | 切换到下一个语言选项 |
| SET-08 | 点击"返回" | 保存设置，返回上一界面 |

### 验证要点
- [ ] 滑块值是否实时反映在数字显示上
- [ ] 全屏切换是否立即生效
- [ ] 返回时设置是否已保存
- [ ] 再次打开设置面板时是否恢复之前的值

## 11. 界面导航流程

```
MainPanel
  ├──→ CreateRolePanel → TownPanel
  ├──→ SettingsPanel (ShowPanel, 可Back)
  └──→ (ContinueGame) → TownPanel

TownPanel
  ├──→ DungeonPanel (ReplacePanel)
  ├──→ ShopPanel (ShowPanel, 可Back)
  ├──→ SkillLearnPanel (ShowPanel, 可Back)
  ├──→ RoleInfoPanel (ShowPanel, 可Back)
  └──→ MainPanel (ReplacePanel, 存档退出)

DungeonPanel
  ├──→ BattlePanel (ShowPanel, 战斗结束Back)
  ├──→ ShopPanel (ShowPanel, 可Back)
  ├──→ BagPanel (ShowPanel, 可Back)
  ├──→ RoleInfoPanel (ShowPanel, 可Back)
  └──→ TownPanel (ReplacePanel, 返回城镇)

BattlePanel
  ├──→ DungeonPanel (胜利Back)
  └──→ TownPanel (失败ReplacePanel)
```

### 验证要点
- [ ] ShowPanel的面板能否正确返回上一级
- [ ] ReplacePanel的面板不会返回到被替换的面板
- [ ] 连续打开多个ShowPanel面板后Back是否按栈顺序返回
