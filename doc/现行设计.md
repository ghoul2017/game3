# 方块与地下城

本设计以《项目设计.txt》的六条初始需求为依据，参考本地《方块地牢2》截图的房间探索与同屏战斗。初始需求原文保留。旧 feature_list.json 与 progress.txt 是开发历史，不作为当前完成证据。

## 游戏目标与循环

玩家从余烬镇出发，逐间打开被迷雾遮挡的地下城，选择战斗与补给路线，获得等级、技能、装备和宝物。资源不足时返回城镇，在旅馆恢复、交易装备、研习跨职业技能，再次从第一层进入探索。击败第十层的深渊守门者即完成本轮冒险。

地牢共十层，前五层为遗忘地窖，后五层为沉没圣所；第五、十层有首领。每层采用42×30的地图空间，入口为居中的2×2区块，从入口向外连接功能块，并预留内部虚空。楼层不设固定区块总数，按可用面积与占地率生成，区块数量随尺寸组合、密度和种子变化。区块大小不同，直接共边才相邻；没有通道块，虚空不能点击、通过或隔空显露另一侧。点击已显露房间直接交互，清理后只显露直接相邻区块；未解决敌人和未破坏障碍不能充当探索跳板。生成时保证不破坏障碍也有完整通关路线。

区块尺寸使用明确的候选集合，矩形允许横竖旋转。功能块按数量的抽取权重如下；比例用于控制整体分布，不要求每一层精确凑数，不以拉长区块填补余地。

| 功能块尺寸 | 数量权重 |
| --- | ---: |
| 1×1 | 8% |
| 1×2 | 12% |
| 2×2 | 30% |
| 2×3 | 25% |
| 3×3 | 15% |
| 3×4 | 7% |
| 4×4 | 3% |

中等功能块2×2与2×3占主要部分，少量小块形成细节，少量大块形成空间变化；不生成1×3、1×4、2×4或其他未列出的功能块。墙与屏障使用1×1、1×2、1×3、1×4，数量权重分别为15%、35%、30%、20%，横竖均可。宽或高为1的区块只显示图标，名称、敌人生命或破坏条件通过悬停查看，当前敌人状态仍显示在右侧战斗区。

floors.json 的 contentMinPercent/contentMaxPercent 为功能块占内框面积的百分比范围，当前48%～58%；obstacleMinPercent/obstacleMaxPercent 为障碍占地率，当前5%～8%。完整区块落地时可略超过目标面积。生成过程中预留分散的内部虚空，功能块必须与已有功能块共边，障碍在剩余空间中贴边放置；空余面积保持虚空。尺寸及数量权重由 DungeonGenerator 的 ContentShapes/ObstacleShapes 统一定义。

墙块与屏障分别以砖墙、菱形符号及颜色区分。配置 floors.json 的 wallPower、barrierPower 定义破坏门槛，分别比较角色物攻与法攻；成长达标后在战斗外点击一次永久破坏，显露相邻区域，不额外扣除资源。强度不足不改变状态；鼠标悬停显示需求与当前能力。破坏状态保存，返城不会重建。第五、十层首领门禁沿用。

## 城镇、返回与保存

点击小镇中的旅馆建筑免费补满生命和法力，点击集市交易，点击公会研习技能，点击地牢入口直接进入第一层。公会开放五个职业的技能，职业选择决定基础属性、成长和初始技能，不限制后续学习。其他职业的入门技能可以免费研习，进阶技能仍需满足等级、前置技能和金币条件。已学主动技能均进入技能选择栏，被动技能自动生效。

战斗之外可以随时返回城镇。返回时每个已生成楼层的小怪、精英和泉水重新可用；地图、迷雾、宝箱、神龛和已击败首领保留。再次出发固定进入第一层。战败损失当前金币的十分之一，恢复生命和法力后返回城镇，成长与一次性奖励保留。首领战不可逃跑，普通战斗可撤退，撤退会承受一次敌人行动。

每次成功操作后保存完整冒险，包括角色、楼层房间、探索标记和战斗中的生命、法力、状态及敌人行动意图。重启后继续相同局面，不能通过读档重复领取奖励。当前保存结构版本为3，继续使用 adventure-v2.json 文件名，不覆盖旧版 save.json；旧版缺失的地牢状态不能可靠恢复，新冒险从角色创建开始。覆盖已有新版本冒险须在游戏内确认。保存失败显示明确错误，不能提示保存成功。读取结构版本2时，旧通道在内存中转为已破坏墙块，保留占地与邻接，点击可继续揭示相邻区域；读取动作不改写文件，后续有效操作才保存版本3。

## 成长与战斗

战士侧重攻击与流血；游侠侧重先手与毒；骑士侧重护盾和控制；牧师侧重恢复和持续输出；法师侧重法术与控制。基础属性、成长、技能、怪物、掉落、物品、宝物、区域与楼层数值由 Resources/Config 下的 JSON 提供，配置缺失或引用错误直接报错。

普通攻击直接点击敌人区块执行，首次点击即遭遇并出手。技能先在下方选择，再点击目标区块：伤害技能点敌人，治疗、护盾和防御点左侧角色区块。选择技能不消耗法力、不推进回合，目标错误或法力不足时不扣资源；已选技能可以连续点击目标施放，右键恢复普通攻击。旅商点击区块打开三选一报价，购买一份或放弃交易后显露邻接；神殿免费三选一，领取后显露邻接；楼梯同样点击直接交互。实际执行攻击、技能、防御或药水后结算一轮。显示敌人下一步意图，速度决定双方行动顺序，双方均存活且未被控制时各行动一次。法术使用法术攻击，物理攻击使用物理攻击，护盾先吸收伤害；中毒与流血按回合结算，状态到期移除。击败敌人只结算一次经验、金币和掉落。

武器、防具、饰品各一个装备槽。背包装备与药水按数量堆叠，不以界面行数限制收益。装备替换时旧装备回到背包；战斗期间不能交易、换装或学习技能。宝物是独立的永久被动，不占背包，不重复获得，效果由配置字段定义。

## 界面与反馈

地图仅使用程序绘制的轮廓、纯色区块和物件符号。小镇与地牢的空缺保持虚空，无填充通道。中央地图视口为1040×660；地牢按固定地图单位绘制，初始聚焦地图中央入口。滚轮围绕鼠标位置缩放，左键或中键拖动平移，全图按钮查看整层；缩放有上下限，平移限制在内容边界。画面外区块被裁剪且不可点击。回合与背包变化保留地图节点及视角。鼠标按住后移动满16屏幕像素才进入拖动，地图和背包采用相同容差；小于该距离且松开仍位于原按钮内，按一次点击处理。拖动结束不触发区块或物品操作。

左侧保留角色、生命、法力、物攻、法攻、金币和近期记录；右侧保留当前敌人生命、意图与防御／撤退，以及常驻背包；技能在地图下方。近况按文字实际高度紧凑排列，条目间距6像素，按面板可用高度容纳近期记录，保持由旧到新顺序；长记录的完整内容可悬停查看。移除主界面的大段规则与重复状态文字。装备槽、背包物品、技能、属性、敌人及区块的详细说明使用鼠标悬停提示，提示框限制在窗口内，不遮挡点击。未揭示区块不泄露详情。

背包为主界面中的滚动网格，显示类型与数量，顶部显示三个装备槽。左键药水直接使用，战斗中占一轮行动；左键装备在战斗外换装。城镇右键出售单个物品，悬停显示售价。背包独立滚动，不缩放地图；弹窗打开后挡住地图和背包输入。设置、商店和公会保留弹窗；成长页移除，宝物以主界面左下方增益图标显示，悬停查看永久效果。

## 验收

- Unity 与 toc 一致：2022.3.62f3c1；对应 URP 14.0.12。实际导入、编译并构建 Windows 可运行程序。
- 五职业创建、初始技能与成长正确；跨职业学习、被动与存档恢复接通，法术技能确实使用法术攻击。
- 多种随机种子下，十层区块连通，尺寸符合候选集合，汇总分布接近权重，数量随地图空间变化，入口居中，没有通道块，虚空不连接区块，未破坏墙与屏障不阻断正常通关，起点与楼梯存在，首领门禁成立。
- 返城、从第一层重入、普通撤退、战败、两次首领击杀与通关状态完整接通。
- 宝箱、神龛、奖励不重复；小怪和泉水按返回规则恢复。
- 保存并恢复地牢和战斗局面；错误存档明确报错；新旧存档互不覆盖。
- 实际运行检查点击敌人攻击、选技能再点敌人或角色、商人区块直接交易、连续出手后目标节点保留，以及中文、场景、弹窗与不同窗口尺寸；自动模拟用于机制回归，不代替人工游玩评价。

## 已确定的产品边界

用户已确认 PC 横屏、跨职业学习、十层地下城；本轮按这些选择实施。已有存档中的楼层布局与探索收获保留，新生成楼层使用42×30空间、虚空及障碍布局，新建冒险可以从第一层体验新布局。

## 区块档次与旅途奖励

区块按面积分四档：1～2格、3～6格、7～9格、10格及以上。面积仅改变不同怪物的出现概率。当前楼层的普通怪物按 monsters.json 的 spawnRank 排序，小区块偏向低档怪物，大区块偏向高档怪物，中间档平滑过渡。两种候选怪物时，小区块的弱／强概率为80%／20%，最大区块为20%／80%。同种怪物在相同楼层、普通／精英身份下属性和战斗收益一致，不叠加面积倍率；首领保持独立配置。宝箱金币乘以档次，另随机获得物品、宝物或技能奖励。高档区块优先提供允许范围内高等级物品，药水数量随档次增加；高于角色等级的装备可以先收藏。

神殿免费三选一；旅商提供三份不同类别报价，只买一份，也可以放弃交易继续探索。物品、永久宝物、技能学习／升级组成奖励池，类别耗尽后以金币补足。选项首次打开时保存，关闭、返城、读档不重抽；领取后永久清理，禁止重复领取。技能奖励遵守等级与前置要求，学习未掌握技能，已掌握技能最高强化到3级：每级增加20%主动技能威力，被动技能每级增加一份配置属性。技能等级随存档保存。

城镇围绕炉火广场安排旅馆、集市、公会与旧城门，以程序绘制的屋檐、灯窗、门廊和矮墙区分建筑。地图支持左键拖动、中键拖动、滚轮缩放及顶栏四个方向按钮。左下宝物栏使用紧凑增益图标与悬停详情，图标多时可以滚动。

界面不重复显示悬停说明、已学技能去向、设置自动保存等常识提示。旅商与神殿标题仅保留名称，不标注“三选一”；神殿不显示金币余额。选技能和回合结束不再追加操作教学，错误目标与法力不足保留简短反馈。空宝物栏不显示占位文字，按钮直接使用动作名称。战斗结束不显示胜利／到账浮字；宝箱、领奖、探索和楼层切换不再重复显示泛化成功提示。经验、金币和掉落等具体结果保留在近况，伤害数值与失败原因仍可见。奖励卡保留名称、效果摘要与价格，完整效果仍可悬停查看；地图操作集中在全图按钮的悬停说明。
